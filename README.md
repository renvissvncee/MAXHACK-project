# Репозиторий проекта сервиса гостеприимства для Хакатона МАКС

# Проблема
Путешественники по России, особенно молодые люди с ограниченным бюджетом, хотят не только найти доступное место для проживания, но и познакомиться с местными жителями и получить локальный опыт. Однако сегодня эти задачи приходится решать через разные сервисы, а существующие hospitality-платформы требуют платного доступа или не адаптированы под российские реалии. В результате организация поездки становится сложнее и дороже, а возможность познакомиться с городом через его жителей теряется.
